## Connect 4, Rock-Paper-Scissors, & Tic-Tac-Toe Games
Final Project Games for class IS311.

## Overview
This project was created for class IS311
This project includes three fully playable games — Connect 4, Rock Paper Scissors, and Tic Tac Toe which are all all built/organized using simple object‑oriented structure.

## Features
- Connect 4 with win detection
- Rock Paper Scissors with replay option
- Tic Tac Toe with draw/win logic
- Score tracking across sessions
- File saving/loading for persistent game data
- Menu system to select game modes
- Clean, modular OOP structure (classes, methods, encapsulation)
- 
## How to Run!
- Open the project in IntelliJ
- Run Main.java
- Choose a game mode from the menu
- Play and view/update high scores
